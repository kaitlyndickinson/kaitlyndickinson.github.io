College football picks from a model I built, posted before kickoff, unedited.

about

This is a project I started in 2024 as a CLI tool using the College Football Data API. It started as a simple script to automate my picks for ESPN's College Pick'em pool (top 99.9th percentile in 2025, on prompt and data formatting alone using the latest OpenAI model at the time), but I later added a trained statistical model to generate the predictions before passing them to the LLM for formatting. The implementation is private for now, but I posted the unedited results for the first three weeks of 2026.

Realistically, I probably got lucky in 2025 since there was no trained model yet and just an LLM working off data I provided (though, I'd review the outputs every week with friends and other football fans to get feedback and tweak the data being pulled and what gets passed into the prompt). I do think that part held up well, but I can't fully separate "good setup" from "good luck" with one season of results. 2026's the actual test: XGBoost and the LLM working together, and I'm curious how much the baseline ends up shaping the LLM's calls. It's been a learning curve but I ended up with a 71% accurate model on leak-free data.

aside That means it's trained on seasons before the ones it's tested on, not a random shuffle across years, so it can't accidentally learn from information it wouldn't actually have at prediction time. That's a common pitfall where sports models look great in testing and fall apart in the real world.

Picks generated before kickoff each week count, whichever model I actually ran (or the best of a few, on weeks I ran more than one), not just the weeks I remembered to click submit on ESPN. LLM + Baseline is the app's normal mode: the quant model's win probability feeds the LLM prompt, and the LLM makes the final call. Baseline only is the same quant model with no LLM step, tracked purely as a comparison.

▸Week 3, 2026

Posted Sep 22, 2026

⚠️ Not actually submitted to ESPN this week. I did run the model before kickoff like usual, I just forgot to enter the picks in the pool itself, so this week doesn't count toward my real ESPN pool standing (still counts toward the season tracker above though, since that one only cares about picks generated before kickoff). Since I had the model output anyway, I ran it as a comparison: Claude Opus 5, Claude Fable 5, and the raw XGBoost baseline (statistical model only, no LLM at all) against the same 10 games, to start separating how much of the accuracy is the underlying stats vs. the LLM layer on top of it. Fable was the better of the two LLM runs this week (7-3 vs. Opus's 6-4), so that's the number counted in the season tracker above.

All three approaches whiffed on the same three games: Louisville/SMU, Maryland/Virginia Tech, and South Carolina/Mississippi State, all double-digit upsets the underlying stats didn't see coming, so that part isn't an LLM problem. Where the LLMs earned their keep was Kansas/Arizona State: the baseline liked Kansas, both LLMs overrode it to Arizona State, and both were right. Opus's one miss that the baseline got right was the opposite move, overriding the baseline from Ole Miss to LSU, and that single override is the entire gap between Opus's 6-4 and Fable's 7-3 this week.
