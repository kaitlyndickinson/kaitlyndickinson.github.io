Weekly college football picks from a model I built, posted before kickoff, unedited.

about

This is a project I started in 2024 as a CLI tool using the College Football Data API. It started as a simple script to automate my picks for ESPN's College Pick'em pool (top 99.9th percentile in 2025, on prompt and data formatting alone using the latest OpenAI model at the time), but I later added a trained statistical model to generate the predictions before passing them to the LLM for formatting. The implementation is private for now, but I'll be posting the unedited results every week.

Realistically, I probably got lucky in 2025 since there was no trained model yet and just an LLM working off data I provided (though, I'd review the outputs every week with friends and other football fans to get feedback and tweak the data being pulled and what gets passed into the prompt). I do think that part held up well, but I can't fully separate "good setup" from "good luck" with one season of results. 2026's the actual test: XGBoost and the LLM working together, and I'm curious how much the baseline ends up shaping the LLM's calls. It's been a learning curve but I ended up with a 71% accurate model on leak-free data.

aside That means it's trained on seasons before the ones it's tested on, not a random shuffle across years, so it can't accidentally learn from information it wouldn't actually have at prediction time. That's a common pitfall where sports models look great in testing and fall apart in the real world.


I'll keep this updated with weekly posts, and post a full summary at the end of the season.
