ESPN College Pick'em Predictor

Blog ↗

A project I made for fun to automate my picks for ESPN's College Pick'em pool every week. It started in 2024 as a CLI that pulled college football data into an LLM, and in 2026 I added a trained XGBoost model to every call. It makes better picks than I do (it's peaked in the 99.9th percentile). Code is private for now, but I posted the first three weeks of 2026's picks publicly.

learned How to ground LLM prompts in a source of truth: an XGBoost model I trained on leak-free data (71% accurate) that the LLM reasons against.
